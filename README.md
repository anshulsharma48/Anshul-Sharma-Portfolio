# Anshul Sharma — Portfolio

A compact, recruiter-focused portfolio built with React + Vite + normal CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The production files will be created in `dist/`.

## Deploy on Vercel

1. Create a GitHub repository and push this project.
2. Sign in to Vercel with GitHub.
3. Import the repository.
4. Vercel detects Vite automatically.
5. Build command: `npm run build`
6. Output directory: `dist`
7. Deploy.

No `vercel.json` is required for this setup.
